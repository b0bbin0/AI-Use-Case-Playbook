Step 1 — Discover

Finding AI Opportunities

Focus on three universal pain point categories that signal high-value AI applications in any org.

🦕 Repetitive Low-Value Tasks

Work that consumes time but doesn't need strategic thinking — the employee's "anti-to-do list."

Data formatting, report gen, email drafts, meeting notes

🚫 Skill Bottlenecks

Projects stall waiting on another team — data science, design, legal, or dev.

Waiting on data analysis, design assets, developer resources

🤔 Navigating Ambiguity

Open-ended challenges where getting started is the blocker. AI acts as a catalyst.

Brainstorming, strategy drafts, market sizing, research

📋 Workshop Discovery Checklist

Run this at the start of a workshop. Ask teams to answer each question, then cluster results into themes.

Anti-to-do list: What recurring tasks do you find annoying or wish you could hand off entirely?
Blockers: Where do you struggle to get started, or frequently stall on projects?
Skill gaps: What tasks require waiting on another team (design, data, dev, legal)?
Ambiguity: Where do projects stall because no one knows the first step?
Data graveyard: What data exists that no one has time to analyze or act on?

Step 4 — Pick Your Model

AI Model Selection Framework

Once you've discovered and prioritized your use cases, choose the right AI model for each. Not all tasks need the same tool — matching model to task drives cost, performance, and speed.

🌳 Decision Tree: Which Model Tier?

🔒 Does the data need to stay on-premises or in a private cloud?
→
Open-source / self-hostedLlama 4, Mistral, Qwen, DeepSeek — full data control, no external API calls
⚡ Is speed and cost the primary constraint (high-volume, low-stakes tasks)?
→
Lightweight / fast tierClaude Haiku 4.5, GPT-5.6 Luna, Gemini 3 Flash — 10–50x cheaper, near-instant responses
📄 Does it need to read 50+ page documents, codebases, or large data corpora?
→
Long-context modelClaude Sonnet (up to 1M tokens), Gemini 3 Pro (1M tokens) — built for large-document reasoning
💻 Is code generation, review, or debugging the primary use case?
→
Code-optimized modelClaude Fable 5, GPT-5.6, GitHub Copilot — strong on reasoning + syntax
🖼 Does the task involve images, audio, video, or mixed media?
→
Multimodal modelGPT-5.6, Claude Fable 5, Gemini 3 Pro — natively handles images, PDFs, audio
🧠 Does it require deep multi-step reasoning, math, or complex judgment?
→
Reasoning-optimized modelClaude Fable 5, GPT-5.6 Sol, Gemini 3 Pro — slower but significantly more accurate on hard problems

🛠 Build vs. Buy vs. Integrate

Matching deployment model to use case scope prevents over-engineering and under-delivering.

When to Buy
💳 Enterprise Seat
  • Under 50 users
  • General productivity tasks
  • No proprietary data integration
  • Need fast deployment
  • Budget under $50K/yr
Examples: ChatGPT Edu, Claude for Enterprise, Gemini for Education, Microsoft 365 Copilot
When to Integrate
🔌 API / Plugin
  • Specific workflow to automate
  • Existing tool needs AI layer
  • Moderate customization required
  • IT team can own maintenance
  • $50K–$200K scope
Examples: Slack AI, Salesforce Einstein, HubSpot AI, custom API wrappers
When to Build
🏗 Custom System
  • Proprietary data as the moat
  • Unique workflow not off-shelf
  • Scale justifies engineering cost
  • Competitive differentiation goal
  • $200K+ investment
Examples: Internal RAG systems, agentic pipelines, fine-tuned industry models

✨ Use Case Development Process

A repeatable, scalable process for turning use cases into production AI. Works for any team, any org.

1. Design: Business user defines purpose, scope, and audience in a 2-page brief.
2. Prepare: SME gathers relevant data to shape the use case around best practice.
3. Build & Test: Tech lead builds the system, integrates datasets, and tests for accuracy and safety.
4. Launch: Full team deploys and creates a user guide for rollout.
5. Pivot & Scale: Use feedback loops to iterate, optimize, and share across the organization.
